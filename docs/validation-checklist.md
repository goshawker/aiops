# AIOps 付费意向验证清单

## 目标

验证 10 家企业的付费意向，收集需求反馈。

## 验证方法

### 1. 产品演示（15 分钟）

- [ ] 仪表盘总览（健康分、告警趋势、资源使用）
- [ ] 指标监控（PromQL 查询、实时图表）
- [ ] 日志管理（全文搜索、级别筛选）
- [ ] 告警管理（事件聚合、确认/解决流程）
- [ ] 异常检测（River 在线学习演示）
- [ ] 根因分析（因果图可视化）

### 2. 核心问题（访谈问卷）

**痛点验证：**
1. 您目前使用什么工具做运维监控？（Prometheus/Grafana/Zabbix/商业产品/自研）
2. 最大的运维痛点是什么？（告警风暴/定位慢/工具分散/成本高/其他）
3. 每月因运维问题造成的业务损失大约是多少？

**产品匹配：**
4. 我们的方案哪个功能最有价值？（异常检测/根因分析/告警降噪/AI 摘要/其他）
5. 缺少哪些关键功能？
6. 是否需要私有化部署？（必须/可选/不需要）

**付费意向：**
7. 如果定价 ¥X/月（按主机数），您会考虑吗？（一定会/可能会/不会/需要审批）
8. 决策流程是怎样的？（IT 负责人决定/需要采购审批/需要 PO 测试）
9. 预计什么时候可以开始试用？

**竞品对比：**
10. 与现有方案相比，我们的优势是什么？

### 3. 目标客户画像

**理想客户：**
- 50-500 台服务器的中型企业
- 使用 Prometheus 但缺乏高级分析能力
- 有信创合规要求（Kylin/ARM）
- IT 团队 3-10 人
- 年运维预算 ¥10-50 万

**行业分布：**
- 金融（银行/保险/证券）
- 政府/公共事业
- 制造业
- 医疗
- 教育
